T sẽ thiết kế MLflow thành trung tâm của Model Lifecycle:

                    DATA
                      ↓
                Dataset v1
                      ↓
              Training Pipeline
                      ↓
              ┌───────────────┐
              │    MLflow     │
              │               │
              │ Experiment    │
              │ Parameters    │
              │ Metrics       │
              │ Artifacts     │
              │ Model         │
              └───────┬───────┘
                      ↓
               Model Registry
                      ↓
              CatDogClassifier
                 v1 / v2 / v3
                      ↓
                Evaluation
                      ↓
                 Approval
                  ↙     ↘
              Reject    Approve
                           ↓
                       Production
                           ↓
                     Model Serving

Những thứ m đã học có thể apply

1. MLflow Experiment Tracking

Mỗi training run:

Run #12
├── Dataset Version: v3
├── Epochs: 10
├── Learning Rate: 0.0005
├── Accuracy: 95.2%
├── Precision: 95.0%
├── Recall: 95.4%
├── F1: 95.2%
└── Model Artifact

2. MLflow Model Registry

CatDogClassifier
├── v1 → Production
├── v2 → Rejected
└── v3 → Staging

3. Model Versioning

Mỗi model version giữ metadata:

Model v3
├── Dataset: v3
├── MLflow Run: abc123
├── Accuracy: 96.1%
├── Created: ...
├── Approved By: ...
└── Status: Production

4. Model Promotion

Không phải:

Train → Production

Mà:

Train
↓
MLflow
↓
Register
↓
Evaluate
↓
Approval
↓
Production

5. Model Serving

Đây chính là requirement của đề:

FastAPI
↓
MLflow Registry
↓
CatDogClassifier
↓
Production

Không hard-code:

model_v3.keras ❌
Và có thể tận dụng luôn kiến thức MLflow architecture m đã học

Ví dụ:

                 MLflow Tracking Server
                         │
              ┌──────────┴──────────┐
              ↓                     ↓
        Backend Store          Artifact Store
        PostgreSQL              MinIO
              │                     │
              └──────────┬──────────┘
                         ↓
                  Model Registry

Nếu m muốn project show đúng kiến thức MLOps course, t thậm chí recommend dùng:

MLflow + PostgreSQL + MinIO + Docker Compose

thay vì chỉ chạy MLflow local.

Vậy lúc presentation m có thể giải thích được luôn:

Tracking Server → Backend Store → Artifact Store → Model Registry → Model Serving
