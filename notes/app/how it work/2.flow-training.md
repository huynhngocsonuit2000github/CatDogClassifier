# 2. How "Training" works

This describes the Training service (Step 2) — what happens when the UI (or
`curl`) kicks off a training job, and how a run ends up in MLflow.

## Overview

The Training service does **not** own the data. It points at the **shared DVC
repo** that the Data Management service maintains, and for each training job it:

1. **pulls** the chosen dataset version from MinIO via DVC,
2. trains a **MobileNetV2** transfer-learning classifier,
3. **logs** the run to **MLflow** (params, metrics, model, artifacts).

| Layer | Tool | Role |
| --- | --- | --- |
| Data source | DVC (shared repo) | Materialises `datasets/vN/` on demand |
| Model | TensorFlow/Keras | Frozen MobileNetV2 → GAP → Dense(1) |
| Tracking | MLflow (Docker) | Records every run + stores the model |

## The flow

```
POST /train {dataset_version, epochs, ...}
  └─ validate version exists (shared index.json)
  └─ job id  ──▶ background thread
                    │
                    ├─ dvc pull datasets/vN.dvc   ◀── MinIO (s3://datasets)
                    ▼
              datasets/vN/  (cats/ + dogs/)
                    │
                    ├─ image_dataset_from_directory (80/20 split)
                    ├─ MobileNetV2 (frozen) + Dense(1, sigmoid)
                    ├─ model.fit(...)
                    ▼
              mlflow.start_run()
                    ├─ log_params   (version, epochs, batch, lr, image_size)
                    ├─ log_metrics  (loss, accuracy, val_loss, val_accuracy)
                    ├─ log tensorflow model
                    └─ log artifacts (metadata.json, metrics.json)
```

### The job lifecycle (in-memory)

```
starting ──▶ pulling ──▶ training ──▶ finished      (success)
     └──────────────────────────────▶ failed        (dvc/train error)
```

`POST /train` returns `202` + `job_id` immediately; the real work runs in a
background thread. Poll `GET /jobs/{job_id}` for status; list everything with
`GET /runs` (reads back from MLflow).

## Where things live

| Place | Content |
| --- | --- |
| Shared `../data-management/data/datasets/vN/` | Pulled training images |
| Shared `../data-management/data/.datasets/index.json` | Version catalog (read-only here) |
| MLflow SQLite (`mlflow_data` volume) | Run metadata |
| MLflow artifacts (`/mlflow/mlartifacts`) | Logged models + artifacts |
