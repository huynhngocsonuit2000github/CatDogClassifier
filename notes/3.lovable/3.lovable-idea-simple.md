# Lovable Idea — Cat/Dog MLOps Dashboard (Outline)

> Paste into Lovable. Build a **front-end demo** (React + TypeScript + Tailwind + shadcn/ui) driven by **mock data**. Real backend (FastAPI + MLflow) is wired later behind a `src/services/*.ts` layer.

## Layout

- Left sidebar + top bar (with a "Production version" status pill). Light/dark mode.

## Pages

1. **Dashboard** — overview: KPI cards + production model + recent runs + accuracy chart.
2. **Data Management** — dataset versions + upload & validate flow.
3. **Training** — training config form + runs list + compare.
4. **Model Registry** — model versions + Approve / Reject / Promote to Production.
5. **Prediction** — upload image → Cat/Dog result with confidence (serves current Production model).

## Notes

- Use realistic mock/seed data so every page looks populated.
- Keep data access behind async service functions (swap to real API later).
